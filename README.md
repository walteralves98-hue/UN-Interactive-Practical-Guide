# ADRA - Interactive Practical Guide

Static searchable website based on the supplied 2026 ADRA guide. All source text is in `public/data.json`, with supporting diagrams in `public/`.

## Deploy
Upload the contents of `public/` to any static web host, or push this repository to GitHub and import it into Vercel. Vercel framework preset: **Other**. Set **Output Directory** to `public` and leave the build command empty. No API keys, database, or login needed.

## PDF
The top-right **Download Full Guide (PDF)** button downloads the original 22-page guide converted to PDF. The PDF is stored in `public/`.
